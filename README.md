# MATLAB Projects

A collection of three small MATLAB projects.

| Project | What it does | Status |
|---|---|---|
| [Energy Simulation](Energy%20Simulation/) | Estimates a battery's capacity, voltage, energy use and remaining cycle life before and after a driving task | README, figures and example script |
| [White Collar Crimes](White%20Collar%20Crimes/) | Analyses M-scores before and after IFRS adoption in Colombia, Saudi Arabia and the UAE, using trend plots and neural networks | README, figures and example script; runs on synthetic data |
| [Car Model Detection](Car%20Model%20Detection/) | Detects the make and type of a vehicle from images, using number-plate and headlight detection (three versions) | README, figures and example script; photos not included |
